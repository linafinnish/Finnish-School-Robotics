
# Finnish School Robotics

## What Is Robotics?

Robotics is the study of **robots** and how they are designed, built and programmed.

Robots are machines that can perform tasks by following instructions.

## What Is an RGB LED?

An RGB LED is a light that can produce different colours by mixing red, green and blue light.

RGB stands for:
- Red
- Green
- Blue

## How Do We Change RGB LED Colours?

We can use Python commands in mBlock to control the RGB LEDs on mBot2.

Each colour has a value from 0 to 255.

For example:

1. Red: (255, 0, 0)
2. Green: (0, 255, 0)
3. Blue: (0, 0, 255)

By changing these values, we can create different colours.

## What Happens When We Turn Off All RGB LEDs?

When all RGB values are set to zero, the LED lights turn off.

The RGB value is (0, 0, 0).

## Robots in Everyday Life

Robots are used in many different places.

Three examples are:

1. Robot vacuum cleaners help clean houses.
2. Industrial robots help build cars in factories.
3. Medical robots help doctors with certain operations.

## Why Is Robotics Important?

Robotics helps people complete tasks faster, more safely and more accurately.
